#  Simple Calculator

A clean and responsive calculator built with **HTML, CSS, and JavaScript**.  
This project demonstrates **event delegation**, **CSS Grid layout**, and **basic mathematical logic** in code.

---

##  Features
- Grid-based button layout using **CSS Grid**
- Supports basic operations: `+`, `-`, `*`, `/`
- Decimal point (`.`) and plus/minus toggle (`±`)
- Clear (`C`) and equals (`=`) functionality
- Responsive design with modern styling
